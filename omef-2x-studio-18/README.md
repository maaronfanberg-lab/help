# OMEF Studio 18 — Responsive mathematical art

[Open the HTTPS app](https://raw.githack.com/maaronfanberg-lab/help/omef-2x-rainbow-live-20261120/omef-2x-studio-18/index.html)

Single-file static app with 909-coordinate Stage D source-conditional OMEF mathematics. Its numerical RK4 and matched-state derivative calculations run in a browser Web Worker, separately from the touch UI. Mobile Focus mode provides a large slider and unobstructed sculpture; All sliders provides a single-column advanced drawer.

The linked GitHub Actions workflow runs mobile Chromium regression tests automatically on relevant pushes and pull requests. GitHub hosts source and runs those *offline tests*; it does **not** provide a live server for arbitrary interactive simulations. The Worker still computes on the user's device.

All original Step-14D historical calibration is **not** present. Stage D uses synthetic source operands and finite legacy replay. View magnification is display-only; the raw 909-coordinate mathematical derivative differences are reported separately. Source files and local test scripts are in the downloadable ZIP package distributed in ChatGPT. iPhone Safari remains untested.
